# CSS Challenge — Layout & Animation Showcase

## Objective

This project demonstrates practical CSS skills through three focused challenges:

1. Responsive Flexbox feature-card layout
2. Responsive CSS Grid layout with six items
3. Subtle CSS transition and transform animation

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Transitions
- CSS Transform
- Responsive Media Queries

## Features

### Flexbox
- Three cards in a horizontal row on desktop
- Cards stack vertically on smaller screens
- Uses `justify-content`, `align-items`, `gap`, and flexible card widths
- Hover interaction feedback

### CSS Grid
- Six grid items
- Uses `repeat()` and responsive column sizing
- Consistent spacing, alignment, borders, and shadows
- Rearranges from three columns to two and then one column

### Animation
- Card lift interaction using `transition` and `transform`
- Button hover scale interaction
- Subtle motion designed to support the UI without distracting from it
- Reduced-motion support for accessibility

## How to Run

No build tools are required.

1. Download or clone the project.
2. Open `index.html` in a browser.

For responsive testing, use browser Developer Tools and switch between desktop and mobile device sizes.
